# 💰 Smart Expense Tracker

A modern full-stack Expense Tracker web application built using React, Node.js, Express, and MongoDB.

Track your daily expenses, manage monthly budgets, analyze spending patterns, and visualize your financial data with interactive charts.

---

## 🚀 Live Demo

🔗 https://smart-expense-tracker-theta-eight.vercel.app

---

## ✨ Features

- 🔐 User Authentication (Login/Register)
- 💸 Add, Edit & Delete Expenses
- 📊 Expense Analytics Dashboard
- 📈 Monthly Spending Charts
- 💰 Monthly Budget Management
- 🌙 Dark Mode Support
- 📱 Fully Responsive Design
- 📂 Export Expenses as CSV
- 🔎 Search & Filter Expenses
- 📌 Category-wise Expense Tracking
- 🎨 Modern UI with Tailwind CSS

## ⚙️ Installation & Setup

### 1️⃣ Clone Repository

```bash
https://github.com/pratyushk072-sudo/smart-expense-tracker.git
```

---

### 2️⃣ Backend Setup

```bash
cd backend
npm install
npm run dev
```

Create a `.env` file inside backend folder:

```env
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
PORT=5000
```

---

### 3️⃣ Frontend Setup

```bash
cd frontend
npm install
npm run dev
```
